    stack与queue¶

    Note

    stack 和 queue 不是新的底层容器，而是容器适配器。它们的价值在于限制接口，让你以“栈”或“队列”的语义来使用底层容器。

    1. stack¶

    语义¶

    后进先出（LIFO）

    常用接口¶

    std::stack<int> st;
st.push(1);
st.top();
st.pop();

    底层¶

    通常基于 deque（也可以基于 vector）

    2. queue¶

    语义¶

    先进先出（FIFO）

    常用接口¶

    std::queue<int> q;
q.push(1);
q.front();
q.back();
q.pop();

    底层¶

    通常基于 deque

    3. priority_queue¶

    语义¶

    优先级最高元素先出

    常用接口¶

    std::priority_queue<int> pq;
pq.push(3);
pq.push(1);
pq.push(5);
pq.top(); // 5

    底层¶

    通常基于堆（heap），常见底层容器是 vector

    4. 为什么说它们是适配器¶

    因为它们： - 不暴露底层容器全部接口 - 只暴露符合栈/队列语义的操作
